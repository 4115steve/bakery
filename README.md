Step 2: Plan Your Website Structure

1. Outline the content for four pages: index.html, products.html or services.html, about.html, and contact.html or events.html.
2. Decide where the required elements will appear, including relevant images, one figure with a caption, one responsive image using the <picture></picture> element, one audio or video element with fallback text, and the required form.

4. Ensure your content decisions align with your selected client’s goals, audience, and tone.
_________________________________________________________
Step 3: Build Your HTML Pages
Create four separate HTML files in GitHub Codespaces using proper boilerplate structure.

1. Include one h1 per page, along with header, nav, main, and footer elements.
2. Build consistent navigation using an unordered list and relative paths.
3. Add the required provided media and embed at least one audio or video element using HTML with fallback text.
4. Include one complete form with proper labels, fieldset, legend, and built-in validation attributes.
5. Do not include CSS or JavaScript in this Touchstone Task.
___________________________________________________________
Step 4: Review Your Work
Review each page in GitHub Codespaces and correct any errors.

1. Confirm a logical heading hierarchy and meaningful alt text.
2. Ensure all internal links function correctly.
3. Verify that all required elements are included and properly structured.
4. Make sure your content, media, and form choices match your selected client.

Common Mistakes to Avoid

1. Using generic content that does not match the selected client
2. Missing or vague alt text
3. Forgetting fallback text for audio or video
4. Using broken or incorrect relative links
5. Leaving out required form elements such as labels, fieldset, or legend
6. Submitting screenshots instead of pasting code as text
7. Your website should not only include the required HTML elements. It should also reflect the purpose, audience, and content needs of your selected client.
